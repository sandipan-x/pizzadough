# PizzaDough

Calculate perfect pizza dough with baker's percentages. Scale by dough balls, adjust hydration, and plan cold fermentation with exact ingredient weights.

## Features
- Tab-based dough bench: calculator, baker's-percentage reference and cold-ferment planner
- Hydration slider with handling-difficulty guidance from 55% to 75%
- Cold-ferment toggle that auto-adjusts yeast and shows the fridge schedule
